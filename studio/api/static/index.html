Importer une collection

Un collection.json regroupe plusieurs dépôts liés (générés côté mainteneur via studio repos build --collection-label/--collection-group) pour un seul « look » cohérent — colle l'URL du manifeste (ou son chemin local), puis choisis les variantes (un seul choix par groupe) et les compléments (tous cochés par défaut) avant d'importer.
